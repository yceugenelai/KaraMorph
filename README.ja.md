歌いたい曲がカラオケに入っていない、いつもの曲を違うジャンルで歌ってみたい。KaraMorph は、そんな「自分好みに歌う」ための Windows 向けカラオケアプリです。繁体字中国語・英語・日本語の UI に対応しています。

## 主な機能と特長

- **手持ちの MP3 をカラオケ音源に**：ボーカルを自動で分離し、そのまま歌える伴奏を作成します。
- **AI でアレンジ変更**：同じ曲を別のスタイル（例：ラウンジジャズ）に変更できます。
- **歌詞**：歌詞を自動検索、または自分で入力・貼り付けできます。
- **背景画面**：歌唱中の背景画像用の検索キーワードを自動生成し、ドラッグ＆ドロップで曲ごとに背景を設定できます。
- **リアルタイム調整**：歌唱中に速度（0.7–1.3倍）とキー（±6半音）を変更できます。
- **プレイリストと録音**：自分だけの歌唱プレイリストを作り、マイクで歌声を録音できます。

## 動作確認環境

## クイックスタート

MP3 を1曲ジャズ風の伴奏に変えて、歌うプレイリストに追加する例です。プログラミングや Python のインストールは不要です。

1. **ダウンロード**：[Releases](https://github.com/yceugenelai/KaraMorph/releases) を開き、使いたいバージョンの **Assets** を展開して `KaraMorph-bootstrap-poc.zip` をダウンロードします。
2. **展開して起動**：ZIP を右クリック →「すべて展開」で書き込み可能なフォルダー（例：デスクトップ）へ展開し、`KaraMorph.exe` をダブルクリックします。ZIP 内や Program Files 内では実行しないでください。
3. **初回セットアップ**：表示言語を選び、人声分離と ACE-Step を選択したまま準備を開始します。インターネットに接続した状態で、キャッシュ込みで約35～40 GiBの空き容量が必要です。
4. **input フォルダーを設定**：`KaraMorph.exe` と同じフォルダー内に `input` フォルダーを作成します。「設定」の「音楽フォルダー」で「選択…」からこのフォルダーを選び、「設定を保存」を押します。
5. **曲を1つ追加**：使用する権利のある MP3 を `input` へコピーし、「楽曲管理」で「曲を再読み込み」を押します。
6. **人声を分離**：曲を選択して「人声を一括分離」を押します。完了後、曲を展開すると「伴奏のみ」が表示されます。
7. **歌詞を取得**：曲を選択したまま「歌詞を一括取得」を押します。見つからない場合は、その曲の「素材」から手動で検索するか、自分の歌詞を追加できます。歌詞がなくても再生できます。
8. **好きなスタイルに変更**：曲の「バージョン作成」を押し、「スタイル」で「ラウンジジャズ」を選び、「スタイル版を作成」を押して完了を待ちます（AI 処理には時間がかかる場合があります）。
9. **プレイリストに追加**：曲を展開し、完成した版（または「伴奏のみ」）の「プレイリストに追加」を押します。
10. **歌い始める**：「歌う」タブで曲を選び、「再生」を押します。リストを残すには「プレイリストを保存」を押してください。

必要な権利を取得した音楽・歌詞・画像のみを使用してください。詳しくは下記の[ライセンスと法的注意](#ライセンスと法的注意)を参照してください。

### 初回セットアップ

Python や Git の別途インストールは不要です。繁体字中国語・英語・日本語を選択できます。初回は英語、以降は保存した言語を使います。ボーカル分離と ACE-Step は既定で選択され、このフォルダーに Python 環境、モデル、固定版 ACE-Step ソースを準備します。ZIP のサイズはインストール後のサイズではありません。

不要な機能は選択を外せます。基本再生と再生中の速度／キー調整には AI モデルは不要で、初回準備時に SoundTouch をダウンロードして検証します。速度／キーを変更した新しいバージョンの保存には引き続き ACE-Step 実行環境が必要です。失敗やキャンセル時は準備済みの項目を保持し、再試行または利用可能な機能で開始できます。「設定 → インストール管理」で後から追加できます。通常の起動で未選択の機能が勝手に追加されることはありません。[セットアップとビルド](docs/BOOTSTRAP.md)。

「モデルとコンポーネントの管理」で SoundTouch のインストール・検証状態を確認でき、AI モデルとは別にダウンロード／修復できます。

### ハードウェアとプラットフォーム

AI 処理は NVIDIA GPU を優先します。VRAM が不足する場合や長い曲では、確認後に CPU を使用できますが、時間と大量の RAM が必要です。この版では AMD/Intel GPU の高速化には対応していません。Windows 11 x64 を主対象とし、音声デバイスは個別の動作確認が必要です。WASAPI 排他出力では他のアプリが同じデバイスを使えない場合があります。

### 再生速度とキー

速度の −／+ ボタンは0.1倍ずつ変更します。「その他の設定 → 再生速度／キー」には微調整用の速度スライダーと速度・キーのリセットボタンを残しています。現在の楽曲バージョンとガイドボーカルだけに適用され、マイクのモニターと元の録音は変更されません。曲ごとに初期値に戻り、歌詞は楽曲の元の位置に追従します。曲全体の録音では実際に再生した伴奏も WAV に保存して試聴を同期するため、追加のディスク容量が必要です。共有・排他モードの両方に対応し、新しい楽曲バージョンは作成しません。

### 楽曲一覧とデータの場所

楽曲管理の一覧は音楽フォルダーの実際の内容に合わせて更新します。ファイルの追加・削除・移動後は「曲を再読み込み」を押してください。元の音源がなくなった曲は一覧から外れますが、処理結果・録音・素材はディスクに保持します。既存の歌うリストは利用不可と表示され、元のファイルが戻ると復元できます。永続的な除外リストは使いません。

設定・プレイリスト・ログ・キャッシュは `.app_data/`、モデルは `models/`、処理結果は既定で `outputs/` に保存します。モデルと出力先は UI で変更できます。言語変更後は再起動してください。更新は手動です。バックアップ後にデータフォルダーを保持してアプリを入れ替えてください。[制限と公開チェック](docs/RELEASE.md)も参照してください。

### ユーザーデータの移行

アプリのフォルダーは変更できますが、**音楽と処理結果を別のパスにコピーするだけでは、既存のバージョン・録音・プレイリストとの関連を維持できるとは限りません**。楽曲 ID は元の音源のフルパス・サイズ・更新日時を含み、生成音声も絶対パスを使用します。

同じ PC で新しく展開した版を使う場合は、データの場所を維持する方法が簡単で確実です。

1. 新旧のアプリを閉じ、データをバックアップします。元の音楽フォルダーと処理結果フォルダー全体（既定は `outputs/`）を残します。
2. 旧 `.app_data/settings.json` と `last_playlist.json` があれば、新アプリの `.app_data/` にコピーします。診断履歴を残す場合は `logs/` もコピーし、別途保存したプレイリスト JSON も保管します。モデル・Python 環境・キャッシュ・`model-receipts.json` は不要です。
3. 新アプリの「設定」で音楽と処理結果のフォルダーを**元のフルパス**に指定し、設定を保存して「曲を再読み込み」を押します。
4. 元の音源・生成版・録音・プレイリストを確認してから旧アプリのファイルを整理します。

別の PC では、同じドライブ文字とフルパスにデータを配置し、元の音源のファイル名・内容・更新日時を維持してください。自動移行ツールは現在ありません。バックアップを保管してください。

### 軽量 ZIP のビルド

Windows 11 x64 でソースフォルダーから PowerShell を開き、PySide6 がインストールされた Python を指定してください（準備方法は [Python 環境とソースからの実行](docs/DEVELOPMENT.ja.md)）：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build-bootstrap-poc.ps1 -UiPython C:\path\to\python.exe
```

出力は `dist/KaraMorph-bootstrap-poc.zip` です。実行環境・モデル・個人データは含みません。既存パッケージを再ビルドする場合は `-Repack` を追加します。[ビルドの詳細](docs/BOOTSTRAP.md)。
