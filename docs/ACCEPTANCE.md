## Version-dialog correction — 2026-10-07

The speed and key spin buttons were tested with mouse clicks across four Qt styles, including Windows 11. Upper clicks increase values, lower clicks decrease them, and limits are respected. All 32 consumer UI tests passed.

## Validation limits

The recorded results do not certify a separate Windows machine without development tools, every audio driver, live recording, full-length AI conversion or every future release. Build and verify each release archive, extract it to a separate writable folder, and test first-run setup and the intended features before publishing.
