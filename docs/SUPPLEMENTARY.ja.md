## 背景画像

共通背景の既定フォルダーは `outputs/shared_images/` です（出力先を変更した場合は、そのフォルダー内）。初回利用時に同梱の背景をコピーします。画像の追加や既定画像の削除が可能で、ユーザーの画像は上書きしません。[背景画像の追加](../assets/README.md)。

## 初回セットアップ

Python や Git の別途インストールは不要です。繁体字中国語・英語・日本語を選択できます。初回は英語、以降は保存した言語を使います。ボーカル分離と ACE-Step は既定で選択され、このフォルダーに Python 環境、モデル、固定版 ACE-Step ソースを準備します。ZIP のサイズはインストール後のサイズではありません。

不要な機能は選択を外せます。基本再生と再生中の速度／キー調整には AI モデルは不要で、初回準備時に SoundTouch をダウンロードして検証します。速度／キーを変更した新しいバージョンの保存には引き続き ACE-Step 実行環境が必要です。失敗やキャンセル時は準備済みの項目を保持し、再試行または利用可能な機能で開始できます。「設定 → インストール管理」で後から追加できます。通常の起動で未選択の機能が勝手に追加されることはありません。[セットアップとビルド](BOOTSTRAP.md)。

「モデルとコンポーネントの管理」で SoundTouch のインストール・検証状態を確認でき、AI モデルとは別にダウンロード／修復できます。

## ハードウェアとプラットフォーム

AI 処理は NVIDIA GPU を優先します。VRAM が不足する場合や長い曲では、確認後に CPU を使用できますが、時間と大量の RAM が必要です。この版では AMD/Intel GPU の高速化には対応していません。Windows 11 x64 を主対象とし、音声デバイスは個別の動作確認が必要です。WASAPI 排他出力では他のアプリが同じデバイスを使えない場合があります。

## 再生速度とキー

速度の −／+ ボタンは0.1倍ずつ変更します。「その他の設定 → 再生速度／キー」には微調整用の速度スライダーと速度・キーのリセットボタンを残しています。現在の楽曲バージョンとガイドボーカルだけに適用され、マイクのモニターと元の録音は変更されません。曲ごとに1.0倍／キー0から始まり、星ボタンで現在の速度とキーをその曲用に記憶して次回から自動適用します（「オリジナル」ボタンでいつでも初期値に戻せます）。ベスト設定は、プレイリスト・音量設定・録音と同じくプロファイル（`.app_data/profiles/<名前>/`）に属し、曲の内容で照合されるためファイルを移動しても有効です。歌詞は楽曲の元の位置に追従します。曲全体の録音では実際に再生した伴奏も WAV に保存して試聴を同期するため、追加のディスク容量が必要です。共有・排他モードの両方に対応し、新しい楽曲バージョンは作成しません。

## 楽曲一覧とデータの場所

楽曲管理の一覧は音楽フォルダーの実際の内容に合わせて更新します。ファイルの追加・削除・移動後は「曲を再読み込み」を押してください。元の音源がなくなった曲は一覧から外れますが、処理結果・録音・素材はディスクに保持します。既存の歌うリストは利用不可と表示され、元のファイルが戻ると復元できます。永続的な除外リストは使いません。

設定・プレイリスト・ログ・キャッシュは `.app_data/`、モデルは `models/`、処理結果は既定で `outputs/` に保存します。モデルと出力先は UI で変更できます。言語変更後は再起動してください。更新は手動です。バックアップ後にデータフォルダーを保持してアプリを入れ替えてください。[制限と公開チェック](RELEASE.md)も参照してください。

## ユーザーデータの移行

プロファイルを別の PC へ（または新しいバージョンへ）移すには「設定 → プロファイルの移行」を使います。どちらも ZIP 1 つにまとまります。

- **設定をエクスポート**：音量設定、プレイリスト、曲ごとのベスト設定のみ。曲は内容で照合するため、同じ曲があれば適用されます。対応する曲がないプレイリスト項目はスキップされます。
- **すべてエクスポート（音楽を含む）**：音楽ファイル、処理結果、歌詞・画像素材、このプロファイルの録音、共通背景も含みます。インポート時は音楽をその PC の音楽フォルダー（事前に設定）に配置し、パスとプレイリストを自動で対応付けて同じ環境を再現します。ファイルが非常に大きくなる場合があるため、自分の PC への移行にのみ使用してください。
- インポート時に名前を変更できます。同名のプロファイルは確認後に上書きされます。

曲の識別にはフルパスが含まれるため、音楽フォルダーや処理結果フォルダーを手動でコピーして移行しないでください。バージョン・録音・プレイリストとの関連が失われる場合があります。

## 軽量 ZIP のビルド

Windows 11 x64 でソースフォルダーから PowerShell を開き、PySide6 がインストールされた Python を指定してください（準備方法は [Python 環境とソースからの実行](DEVELOPMENT.ja.md)）：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build-bootstrap-poc.ps1 -UiPython C:\path\to\python.exe
```

出力は `dist/KaraMorph-bootstrap-poc.zip` です。実行環境・モデル・個人データは含みません。既存パッケージを再ビルドする場合は `-Repack` を追加します。[ビルドの詳細](BOOTSTRAP.md)。
