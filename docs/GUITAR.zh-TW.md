# 吉他彈唱（選用插件）

[English](GUITAR.md) · [繁體中文](GUITAR.zh-TW.md) · [日本語](GUITAR.ja.md)

全新安裝預設關閉「吉他彈唱」分頁，也不會自動下載插件。在「設定 → 插件管理」勾選「啟用吉他彈唱插件」並儲存設定，分頁就會出現在「MV 匯出」和「設定」之間。第一次使用前，在同一處按「安裝／修復吉他插件」：程式下載 LV-Chordia 與 CPU 執行元件至 `.runtime/guitar`，不會更動既有的分離或風格環境。下載需要網路與磁碟空間；安裝完成後辨識在本機進行。原本已安裝插件的使用者會保留啟用狀態，已儲存的開關設定優先。

「產生和弦譜」、取消處理、譜面版本、Capo、平滑強度及 PDF 匯出位於同一列，播放控制列在其下方。「修正和弦」預設收合，點選標題可展開。指法圖顯示在對應歌詞上方，圖與圖之間會留空；點圖可跳到該和弦的時間。圖中弦線由左到右為第六弦至第一弦，× 為不彈、○ 為空弦，數字 1–4 代表手指；左側的數字是相對 Capo 的起始格。

「指法圖大小」可選小、中、大，預設為小，並隨該版本譜面保存。播放時目前和弦圖會以金色底色、外框及圓點標示；前奏的無和弦區段也會標示。畫面足以容納兩列時，播放到可見區域倒數第二列附近就會提早捲動，保留後續譜面供準備。

在「修正和弦」列表選取該句的一個和弦，按「調整和弦對齊歌詞…」；若和弦跨越多句，先選擇要調整的句子。編輯框會顯示整句歌詞與 `|` 標記，依上方列出的和弦順序移動標記，即可一次調整句首、句中或句尾的多個和弦。例如 `|歌詞|唱完|||` 將後三個和弦放在歌詞後方。請保留原有歌詞與標記數量；歌詞本身的 `|` 和反斜線分別顯示為 `\|` 和 `\\`，請勿修改。可按「恢復自動估算」再保存，還原整句的自動位置。

也可以在譜面中的和弦圖上按右鍵，選「修改這句所有和弦位置…」，直接編輯該圖所在的歌詞行。左鍵仍可跳轉播放位置。

修正只改變譜面排列，不改變和弦或歌詞的播放時間；標記順序對應和弦順序。如果是整句歌詞時間錯誤，請到素材工具調整 LRC。對齊修正分別存於歌曲版本及譜面種類；歌詞文字、時間或和弦區間改變後，舊設定會保留但不會套用到不相符的內容。

譜面頂部預設使用歌曲素材中設定的清單縮圖，沒有設定時使用歌曲封面；標題、歌手與版本也會顯示在旁邊。展開下方「修改譜面資訊」可為這個歌曲版本設定標題、歌手、備註及專用圖片，按儲存生效；這不會修改歌曲檔案或素材原本的縮圖。

按「匯出譜面 PDF…」可將目前的譜面版本、Capo 指型、歌詞及譜面資訊輸出為 A4 PDF。內容較長時會自動分頁，適合列印或分享；播放中的金色位置標記不會輸出。請先產生譜面再匯出。

常見和弦使用內建指型；沒有內建指型時，程式會嘗試依標準調弦、和弦音、低音與手指跨度產生指型，成功後保存到 `.app_data/guitar-voicings.json`，之後可重用。自動指型標有「自動產生」，雖然有檢查音組與基本按法，仍可能不合手或不適合上下文，請自行確認。未支援的和弦記號或找不到符合條件的按法仍顯示「暫無指法圖」。

選擇歌曲與版本，按「產生和弦譜」。原曲／分離伴奏選項使用已分離的伴奏進行分析；若尚無伴奏，請先到「處理歌曲」準備。其他版本使用該版本音源，各自保存譜面。原曲／分離伴奏可以切換兩種播放來源；衍生版本僅提供其本身的音源，避免將不同編曲或速度錯誤對齊。

譜面使用已保存的 LRC 歌詞、版本速度及字幕偏移。可播放、暫停、拖曳進度、點譜面或列表跳轉；播放時會跟隨目前歌詞與和弦。一般 LRC 只有逐句時間，句中和弦與文字的位置是時間比例估算，無法保證逐字準確。沒有 LRC 時仍可查看和弦時間軸。

選擇原始、平滑、標準或簡易譜；變更「平滑強度」並按「套用平滑設定」可重算，不需再次執行模型。雙擊列表修改單一和弦，輸入**實際音高**後自動保存，修改只套用於目前譜面版本。修改依時間區間及原始和弦識別；平滑後區間改變時，舊修改會保留在檔案中，但不會套用到不同區間。重新產生時，含手動修改的舊譜會備份，可按「還原先前譜面」。模型原始輸出不受手動修改影響。

Capo 0–7 格會改變顯示的指型，並隨譜面保存；音檔及保存的實際和弦不變。例如 F# 配 Capo 2 會顯示 E。辨識是估計結果，請聆聽確認；此版本尚無吉他錄音功能。歌曲版本或分析音檔變更後需重新產生。資料保存在輸出資料夾的 `songs/<歌曲 ID>/guitar/`。
