# ギター弾き語り（オプション）

[English](GUITAR.md) · [繁體中文](GUITAR.zh-TW.md) · [日本語](GUITAR.ja.md)

「MV の書き出し」と「設定」の間にある「ギター弾き語り」を開きます。初回は「設定 → プラグイン管理」で「ギタープラグインをインストール／修復」を押します。LV-Chordia と CPU 実行環境は既存の分離・スタイル環境とは別の `.runtime/guitar` にダウンロードされます。インストールにはネット接続と空き容量が必要で、認識はローカルで行います。同じ設定欄で有効／無効も切り替えられます。

コード譜の生成・キャンセル、譜面の種類、カポ、平滑化、PDF 出力は同じ行にあり、その下に再生操作があります。「コードの修正」は初期状態で閉じています。コードフォーム図は対応する歌詞の上に間隔を空けて表示され、図をクリックするとその時刻へ移動します。弦は左から6弦～1弦、×はミュート、○は開放弦、1～4は指番号、左の数字はカポからの開始フレットです。

コード図の大きさは小・中・大から選べ、既定は小で、譜面ごとに保存されます。再生中は現在のコード図が金色の背景・枠・丸印で表示され、イントロのコードなし区間も示します。自動スクロール時も現在のコード図が見えるようにします。

譜面上部には曲の画像素材で選択したサムネイル、未設定時は音楽ファイルのカバーを表示します。下の「譜面情報を編集」から、その曲のバージョン用のタイトル、歌手、メモと画像を変更して保存できます。音楽ファイルや元のサムネイル設定は変更しません。「PDF を出力…」では選択中の譜面、カポのフォーム、歌詞と譜面情報を A4 PDF に出力し、長い譜面は自動で改ページします。再生位置の強調表示は出力しません。先に譜面を生成してください。

一般的なコードには内蔵フォームを使用します。内蔵フォームのない対応コードは、標準チューニング、構成音、ベース音、指の届く範囲から生成を試み、成功した結果を `.app_data/guitar-voicings.json` に保存して再利用します。生成した図には「自動生成」と表示します。構成音と基本的な押さえ方は確認しますが、押さえやすさや曲に合うことは保証できないため、自分で確認してください。未対応のコード記号や適切なフォームが見つからない場合は「フォーム図なし」と表示します。

曲とバージョンを選び、コード譜を生成します。原曲／分離伴奏では、準備済みの伴奏を解析します。伴奏がない場合は先に曲を処理してください。その他のバージョンはそれぞれの音源を解析し、譜面を別々に保存します。原曲と分離伴奏は再生時に切り替え可能です。派生バージョンは、そのバージョンの音源を再生します。

保存済みの LRC 歌詞、バージョン速度と字幕オフセットを使います。再生・一時停止・シークや譜面／一覧からの移動が可能で、現在の歌詞とコードを追跡します。通常の LRC は行単位の時刻のみなので、行内のコード位置は推定です。LRC がなくてもコードの時間軸を確認できます。

原始、平滑化、標準、簡易譜を選べます。平滑化の強さはモデルを再実行せずに適用できます。一覧をダブルクリックしてコードを**実際の音高**で編集すると、現在の譜面の種類に保存されます。編集は元のコードと時間区間に結び付き、平滑化で区間が変わると別の区間には適用されません。再生成時には手動変更を含む旧譜面をバックアップし、「以前の譜面を復元」で戻せます。モデルの原始出力は手動編集とは別に保存されます。

カポ 0～7 は表示するフォームのみを変え、譜面と共に保存されます。音源や保存した実際のコードは変えません。例えば F# はカポ 2 で E フォームと表示されます。認識結果は推定なので試聴して確認してください。ギター録音は未対応です。音源を変更した場合は再生成が必要です。譜面は出力先の `songs/<曲 ID>/guitar/` に保存されます。
